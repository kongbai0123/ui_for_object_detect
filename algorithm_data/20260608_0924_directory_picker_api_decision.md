# 決策記錄：實作本機資料夾選擇器 API
**時間**：2026-06-08 09:24:00

---

## 1. 背景與需求說明
使用者指出需要檢查介面中的「資料夾圖示按鈕 (Folder icons)」是否有作用。
經檢查發現：
1.  首頁的「建立新專案對話框」與「開啟舊專案對話框」中的資料夾按鈕未綁定事件。
2.  「資料頁面」的 Input 欄位右邊的資料夾按鈕亦未綁定事件。
由於 Web 瀏覽器出於安全性考量，原生不支援直接開啟作業系統的「資料夾選擇器」並獲取本機絕對路徑，因此需要發揮「FastAPI 本機後端」的優勢。

---

## 2. 設計方案與實作步驟

### 解決方案：Python Tkinter 後端對話框 + 前端 API 串接
*   **後端設計**：
    在 `server.py` 中新增 `GET /api/project/choose_directory` 端點。
    利用 Python 標準庫中的 `tkinter.filedialog.askdirectory` 啟動 Windows 原生的資料夾選擇器。透過 `attributes("-topmost", True)` 確保視窗強制彈在最前台。
*   **前端設計**：
    1.  給 `index.html` 中資料頁的資料夾按鈕加上 `id="btn-data-choose-dir"`。
    2.  在 `js/app.js` 中綁定三個資料夾選擇按鈕：
        -   `btn-choose-dir` (建立專案 Modal 中)
        -   `btn-choose-load-dir` (載入專案 Modal 中)
        -   `btn-data-choose-dir` (資料頁面中)
    3.  點擊按鈕時發送 API 請求。若成功取得路徑，更新對應的輸入框。
        *若在資料頁中選擇了新目錄，自動向後端發送專案載入請求，直接切換當前專案工作區。*

---

## 3. 優缺點與相容性分析
*   **優點**：
    -   **真正的本機軟體體驗**：解決了 Web 應用無法取得本機絕對路徑的硬傷。
    -   **零依賴**：`tkinter` 是 Python 標準庫，Windows Python 環境預設內建，無須安裝額外依賴。
*   **潛在副作用**：
    -   呼叫 API 時，後端線程會阻塞等待使用者選擇或關閉對話框，但因為這是在本機單人使用，此阻塞對使用者體驗沒有任何影響。
