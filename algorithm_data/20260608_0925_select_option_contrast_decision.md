# 決策記錄：修復下拉選單 Option 的高對比度字體
**時間**：2026-06-08 09:25:00

---

## 1. 背景與問題診斷
根據使用者反饋的截圖，在暗色主題的 Web 介面中，`<select>` 下拉選單展開時出現了嚴重的對比度問題：
*   **現象**：展開的選項列表背景呈現白色，而選項文字卻為白色/淺灰色，導致選項文字幾乎不可見。
*   **原因**：`<select>` 上設定了 `color: var(--text-primary)`（接近白色的 `#f1f1f7`），而瀏覽器原生的 `<option>` 繼承了此文字顏色。然而，某些 Windows 瀏覽器在渲染 option 展開視窗時，會使用預設的淺色背景，造成「白底白字」的低對比度現象。

---

## 2. 解決方案

### 決策：在 CSS 中為 `select option` 明確指定深色背景與白色文字
*   **修改內容**：
    我們將在 `css/styles.css` 中加入對 `select option` 的專屬樣式設定，強制其選項背景為與系統暗色主題一致的深色（如 `#121225`），並使用高對比度的白字（`#ffffff`）。
    這能確保在 Chrome、Edge 和 Firefox 等現代瀏覽器中，展開的選單呈現統一的暗色美學，且文字清晰可見。
