# 決策記錄：一鍵啟動批次檔設計方案
**時間**：2026-06-08 09:08:00

---

## 1. 背景與需求說明
使用者要求在 `yolo` (即專案根目錄 `d:\software\yolo`) 底下建立一個「一鍵開檔」的啟動工具，讓非開發背景的使用者或日常操作能直接雙擊啟動 Python FastAPI 後端服務，並自動用系統預設瀏覽器打開 `http://127.0.0.1:8000` 進行操作。

---

## 2. 設計方案與執行步驟

### 設計方案：Windows 批次檔 (.bat)
*   **檔名**：`d:\software\yolo\start_yolo_ui.bat`
*   **執行步驟**：
    1.  關閉指令回顯，顯示引導文字。
    2.  以最小化新視窗 (`start /min`) 非同步啟動 Python 後端 `python "%~dp0\algorithm\yolo_ui\server.py"`，避免阻塞批次檔自身執行。
    3.  使用 `timeout /t 2 >nul` 延遲 2 秒，等待 Uvicorn 完成連接埠綁定。
    4.  使用 `start http://127.0.0.1:8000` 調用 Windows 系統預設瀏覽器開啟 Web UI。
    5.  提示使用者啟動完畢，並保持視窗按任意鍵退出（後端仍會在背景/最小化視窗正常運行）。

---

## 3. 優缺點與替代方案

### 優點：
- **極致便利**：使用者無須手動開啟終端機並輸入 `python ...` 命令，一鍵即可完成。
- **相對路徑適應**：使用 `%~dp0` 確保無論從何處呼叫，都能正確找到 Python 後端檔案。

### 替代方案：
- *Python 啟動指令檔 (.py)*：使用 `subprocess` 與 `webbrowser` 庫，但 Windows 使用者依然需要滑鼠右鍵選擇開啟方式或在 terminal 執行。批次檔 (.bat) 具備最高的雙擊執行原生便利性。
